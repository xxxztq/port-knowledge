# 港口设备线稿素材说明

共 12 张原创 SVG，对应 `src/data/knowledge.js` 中 12 篇 `kind === '设备'` 的文章。配套数据位于 `src/data/equipment-visuals.js`，导出 `equipmentVisuals` 数组。

所有图均为**教学示意，非工程图**。结构、比例、布置与配置经过简化，用于设备识别和业务交接说明，不构成设备选型、施工或操作依据。图内只保留 1 / 2 / 3 三个可见编号；教学属性同时写入每张 SVG 的 title 和 desc。

## 视觉与接入约定

- 固定 `viewBox="0 0 800 480"`，原始宽高 800 × 480，图像比例 5:3。
- 背景透明，主体采用米白、灰白填充及黑灰细轮廓；无渐变、栅格贴图、脚本或外部素材依赖。
- 文件 ID 以设备文件名为前缀，样式选择器限制在各 SVG 根 ID 内；可内联多个图且避免重复 ID 或样式串扰。
- `points[].x` 与 `points[].y` 为百分数，精确对应编号圆心：`cx = x × 8`，`cy = y × 4.8`。
- 页面覆盖交互时，请让定位容器保持 5:3，图像完整铺满该容器，覆盖元素使用 `left: x%`、`top: y%`、`transform: translate(-50%, -50%)`。使用裁切显示或将点位相对额外留白区域定位会产生偏移。
- SVG 内编号组采用 `pointer-events="none"`；页面可在相同中心叠加可聚焦按钮，并使用数据中的标题和说明提供交互内容。
- 静态资源路径不含 `public/` 前缀；站点有 BASE_URL 时由页面统一拼接。

## 内容依据与示意边界

说明文本依据本仓库设备文章的 summary、sections 与 scope 组织，不新增尺寸、型号、吨位、堆高、跨距或生产能力数字。本次未取得可用的新增厂家在线页面，因此不宣称完成额外厂家核验，也不加入需要型号资料支持的设备能力结论。

- 卸船机选取抓斗式作为代表，不把其外形作为连续卸船机的共同结构。
- 空箱堆高机选取立式门架与侧向取箱装置作为示意，具体抓取方式和多箱能力仍由型号决定。
- 堆取料机选取斗轮式外形，图中堆位、臂架和输送连接用于识别，不表示所有设备都采用斗轮或可同时堆取料。
- RMG 选取侧面交接构图，设备是否自动化、是否有侧向悬臂，以及铁路或端部交接方式均依项目而异。
- AGV 采用无驾驶室平台式外形，感知部件位置仅作示意，不推定具备自行升降能力。
- 泵管罐图为功能连接示意，不是工艺流程图或配管图，不给出介质适用、阀门切换、压力或启停顺序。
- 闸口设备的识别、业务匹配、道闸动作和实际通行记录分别说明，不把识别成功当成放行授权。
