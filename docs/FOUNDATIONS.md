# 港口基础专题

五个专题：`network-choice`（k02 航线腹地）、`governance`（k04 治理边界）、`lifecycle`（k05 设施生命周期）、`environment-city`（k23 环境港城）、`spatial-levels`（k01 空间层级）。入口为 `foundations/`。

每页都有 scenario、diagram、process、handoffs、economics、exception、checks、sources 八个锚点；流程节点包括主体、输入、动作、校验、输出、下游；异常包括发现、影响控制、决策职责、证据、恢复与关闭。三道理解题支持交互反馈，无脚本可展开答案。

所有港口、企业、业务及异常情节为虚构教学设计。流程节点可并行、回退；不是统一行政审批顺序或现场指令。费用按服务主体区分，不提供真实报价或收益保证。

2026-11-23 读取世界银行 Port Reform Toolkit 官方介绍页及模块概要，并确认 UNCTAD 班轮网络专题题名与主题。世界银行主题参考不等于中国适用法规；未声称读完全部工具包。本模块不使用未得到本轮确认的法规版本、生效日期、许可时限、工程参数或作业阈值。出处明确区分来源概念与原创教学模型，具体项目仍需按本港及办理时点核实。

运行 `npm run check:foundations`、`npm test`、`npm run build`、`npm run check:links`。搜索会自动提取这些页面正文，覆盖地图已链接实际流程、异常和练习。
